# 华中农业大学本科生毕业设计LaTeX模板

## 项目简介

本项目为华中农业大学本科生毕业设计论文的LaTeX模板，已初步完成从Word版本到LaTeX版本的封面等格式风格转换。使用本模板可以帮助学生更加规范、美观地撰写毕业设计论文。

## 特性

- ⚠️ **注意**：推荐使用Overleaf在线编辑器。

- ✅ 符合华中农业大学本科生毕业设计论文格式要求
- ✅ 完整的封面格式转换
- ✅ 规范的页眉页脚设置
- ✅ 标准的章节格式
- ✅ 支持中文排版

## 使用方法

1. **下载模板**

从github直接下载ZIP文件

2. **上传到Overleaf**
- 登录Overleaf账号
- 创建新项目，选择“Upload Project”
- 上传下载的ZIP文件

4. **开始编写**
   - 打开主文件 `main.tex` 开始编写论文
   - 根据需要修改封面信息、章节内容等
   - 实时预览编译结果

## 目录结构
```
HZAU_UnderGraduateThesis_Template/
├── main.tex                  # 主文件
├── chapters/                 # 章节文件夹
│   ├── chapter1.tex          # 第一章
│   ├── chapter2.tex          # 第二章
│   └── ...                   # 其他章节
├── Fig/                   # 图片文件夹
│   └── ...                   # 图片资源
├── references.bib         # 参考文献文件
├── README.md                 # 项目说明文件
└── HZAU.cls        # 模板类文件
```
