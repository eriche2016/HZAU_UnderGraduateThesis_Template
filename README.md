# 华中农业大学本科生毕业设计LaTeX模板

## 项目简介

本项目为华中农业大学本科生毕业设计论文的LaTeX模板，已初步完成从Word版本到LaTeX版本的封面等格式风格转换。使用本模板可以帮助学生更加规范、美观地撰写毕业设计论文。

## 特性

- ✅ 符合华中农业大学本科生毕业设计论文格式要求
- ✅ 完整的封面格式转换
- ✅ 规范的页眉页脚设置
- ✅ 标准的章节格式
- ✅ 支持中文排版
- ✅ 兼容Overleaf在线编辑

## 使用方法

### 方法一：通过GitHub下载使用

1. **下载模板**
   - 访问本项目的GitHub仓库
   - 点击绿色的 `Code` 按钮
   - 选择 `Download ZIP` 下载压缩包到本地
   - 解压缩文件到合适的位置

2. **导入Overleaf**
   - 登录 [Overleaf](https://www.overleaf.com) 网站
   - 点击 `New Project` → `Upload Project`
   - 选择刚才下载的ZIP文件进行上传
   - 等待上传完成，项目将自动创建

3. **设置编译器**
   - 在Overleaf项目中，点击左上角的 `Menu` 按钮
   - 在设置选项中找到 `Compiler` 选项
   - **重要：将编译器设置为 `XeLaTeX`**
   - 点击 `Save` 保存设置

4. **开始编写**
   - 打开主文件 `main.tex` 开始编写论文
   - 根据需要修改封面信息、章节内容等
   - 实时预览编译结果
